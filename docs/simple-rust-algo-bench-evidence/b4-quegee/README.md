## Three things in `campaign.jsonl` that look like failures

- **Three parity invocations exited 1.** These are the protocol fixture set at
  each concurrency. `parity.py` exits 1 when any row mismatches, and that set
  always has the four `neo4j-graph` dangling-mass rows B3 reported. The driver
  takes a parity verdict from its file, not from the exit code. Nothing
  disagreed beyond those four rows, and nothing errored.
- **Three parity invocations are marked shared.** In every one, the sightings
  are the resident agent session, pid 1496. Parity verdicts are computed results,
  so these were not rerun.
- **One timed run is marked discarded.** The first `xlarge-one-thread` saw two
  things in its first 35 seconds, both started by the agent running this
  campaign to collect provenance: a second container at 22:02:51Z (a `docker
  run` of `audit.py`) and a `sha256sum` of the xlarge fixtures at 22:03:02Z. It
  was rerun clean from 23:33:03Z.
